countlines

Count the number of black-white transitions along a scan direction.

morphology · image->scalar · EXACT

viprs countlines in.png --direction horizontal
let raster = decode_file(&input)?;
let value = raster.try_countlines(direction)?;
println!("{value}");
<IN>

Input image (single-band, thresholded). Required.

--direction, -d <DIR>

Scan direction for counting transitions. One of: horizontal, vertical. Default: horizontal

labelregions

Label discrete connected regions with unique integer labels.

morphology · image->image · EXACT

viprs labelregions in.png out.v
let raster = decode_file(&input)?;
let result = raster.try_labelregions()?;
save_file(&result, &output)?;
<IN>

Input image (single-band mask). Required.

<OUT>

Output labelled image. Required.

morph

Apply a morphological operation (erode or dilate) using a structuring mask.

morphology · image->image · EXACT

viprs morph in.png out.v --mask MASK --operation erode
let raster = decode_file(&input)?;
let result = raster.try_morph(mask, operation)?;
save_file(&result, &output)?;
<IN>

Input image. Required.

<OUT>

Output image. Required.

--mask, -m <MASK>

Structuring-element mask file (e.g. a 3x3 matrix). Required.

--operation, -o <OP>

Morphological operation to apply. One of: erode, dilate. Default: erode

rank

Rank filter: replace each pixel with the nth ranked value in a window.

morphology · image->image · APPROX

viprs rank in.png out.v --width 3 --height 3
let raster = decode_file(&input)?;
let result = raster.try_rank(width, height, index)?;
save_file(&result, &output)?;
<IN>

Input image. Required.

<OUT>

Output image. Required.

--width, -w <N>

Window width in pixels. Default: 3

--height, -h <N>

Window height in pixels. Default: 3

--index, -i <I>

Rank index within the window (0 = min, size-1 = max, size/2 = median). Default: 4
